# 버블팝

아래에서 같은 색 구슬을 세 개 이상 맞춰 터뜨리는 클래식 버블 퍼즐입니다. 수현이를 위한 판이에요.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:8080` 을 엽니다.

## 조작

- 손가락을 대고 움직여 조준, 손을 떼면 발사
- 키보드 `←` `→` 조준, 스페이스 발사

## 규칙

- 같은 색 3개 이상이면 팡
- 가끔 특수 구슬이 나옵니다 (십자, 자석, 폭탄, 별, 닻 등)
- 막히면 스테이지당 한 번 **선배의 도움**을 쓸 수 있습니다
