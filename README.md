# 버블팝

아래에서 같은 색 구슬을 세 개 이상 맞춰 터뜨리는 클래식 버블 퍼즐입니다. 수림이를 위한 판이에요.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:8080` 을 엽니다.

## 컴퓨터와 휴대폰에 설치

설치한 앱은 인터넷 없이 동작합니다. 웹사이트를 열지 않아도 되고, 점수판은 그 기기에만 저장됩니다. 사이트용 빌드(`npm run build`)와 Vercel 배포는 그대로입니다.

받는 방법:

1. 이 패키징이 `main`에 들어간 뒤 `v1.0.0` 같은 태그를 푸시합니다.
2. GitHub Releases에서 파일을 받습니다.
   - `BubblePop-portable-1.0.0.exe` — 윈도우, 설치 없이 더블클릭
   - `BubblePop-setup-1.0.0.exe` — 윈도우 설치 프로그램. 바탕화면 이름은 버블팝
   - `BubblePop-1.0.0.apk` — 안드로이드. 앱 이름은 버블팝, 화면은 세로

`main`에 푸시하거나 Actions에서 Native builds를 직접 실행해도 Artifacts에서 같은 종류의 파일을 받을 수 있습니다. Release에 붙는 것은 `v*` 태그를 푸시할 때뿐입니다.

윈도우 SmartScreen이 서명되지 않은 앱을 막을 수 있습니다. **추가 정보**를 누른 다음 **실행**을 누르면 열립니다.

안드로이드는 Play 스토어 밖 설치입니다. 파일을 받은 브라우저나 내 파일 앱에서 **출처를 알 수 없는 앱 설치**를 허용한 뒤 apk를 엽니다. 같은 서명으로 만들어진 새 apk는 기존 앱 위에 설치됩니다.

## 조작

- 손가락을 대고 움직여 조준, 손을 떼면 발사
- 키보드 `←` `→` 조준, 스페이스 발사

## 규칙

- 같은 색 3개 이상이면 팡
- 가끔 특수 구슬이 나옵니다 (십자, 자석, 폭탄, 별, 닻 등)
- 막히면 스테이지당 한 번 **선배의 도움**을 쓸 수 있습니다
